The review page shows the airport lighting layout supplied by its division. Check that it covers the area and objects you intend to support before you select a scenery package.

## Read the map

Pan and zoom to inspect the airport. Select a marker or line to open its object card.

The card shows:

- The object name and BARS ID.
- The object type.
- Direction, where the object uses one.
- Stop bar elevation and IHP settings.
- Taxiway light color.

Select the BARS ID in the card to copy it.

<Frame caption="Select an object to see and copy its BARS ID.">
  <img src="/images/v2/Contributions-Review-Object.png" alt="Selected airport lighting object with its name, copyable BARS ID, type, direction, and other object details" />
</Frame>

<Note>
  The division owns the object metadata. The later editor lets you align the object with the scenery, but it does not change the division's operational settings.
</Note>

## Map controls

| Control | What it does |
| --- | --- |
| Zoom buttons | Change the map scale. |
| Pan | Move around the airport. |
| Satellite or Street Map | Switch the base map. The button names the view that is currently active. |
| Object selection | Open the selected object's details and highlight it on the map. |
