At this step, you review the airport lighting data submitted by the owning Division. Check which lighting objects are included and where they are placed before creating your contribution.

<Note>
  The Division must have submitted airport lighting data and enabled contributions for this airport. Without both, you cannot create a draft or submit a contribution.
</Note>

<Frame>
  <img src="/images/v2/Contributions-Review-Airport.png" alt="Review airport page with the BARS lighting layout map, contribution progress tracker, and Create contribution draft action" />
</Frame>

## Read the Map

Pan and zoom to check that the Division's layout covers the areas you want to support. Select a marker or line to see its lighting object details.

The card shows:

- The object name and BARS ID.
- The object type.
- Direction, where the object uses one.
- Stop bar elevation and IHP settings.
- Taxiway light color.

Select the BARS ID in the card to copy it.

<Frame>
  <img src="/images/v2/Contributions-Review-Object.png" alt="Selected airport lighting object with its name, copyable BARS ID, type, direction, and other object details" />
</Frame>

## Next Steps

Once you have reviewed the Division's data, create a draft to match those lighting objects to your scenery package. You can adjust their positions in the editor afterwards. If you already have a draft, you can skip to testing.
