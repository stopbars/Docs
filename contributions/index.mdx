## What Are Contributions?

The **BARS Contribution System** lets you add airport lighting support for default and third-party scenery. Each contribution supports a specific airport and simulator scenery package, making real-time BARS lighting available to pilots using that scenery.

Your contributions help:

- **Expand global airport coverage** - Add lighting support for airports worldwide
- **Support multiple scenery packages** - Increase compatibility with both default and third-party simulator scenery

## The Contribution Flow

<Steps>
  <Step title="Choose an airport">
    Enter its four-character ICAO code.
  </Step>
  <Step title="Review the BARS layout">
    Check the lighting objects supplied by the airport's division. Each object has a BARS ID.
  </Step>
  <Step title="Create a draft">
    Select the matching MSFS or X-Plane scenery folder. The generator compares the scenery with the division layout and marks anything that still needs manual work.
  </Step>
  <Step title="Edit the draft">
    Correct shapes, add missing objects, adjust source-light removals, and clear validation errors in the browser editor.
  </Step>
  <Step title="Test the contribution">
    Prepare the draft, inspect its map preview, and open it in the BARS Pilot Client for an in-simulator test.
  </Step>
  <Step title="Submit for review">
    Add the scenery name, select the simulator, confirm the acknowledgement, and send the tested draft to the BARS team.
  </Step>
</Steps>

## Supported Simulators

<Tabs>
  <Tab title="MSFS">
    Use the airport package from your MSFS 2024/2020 Community folder. The browser editor is experimental for MSFS, so compare the rendered scenery with the simulator before submitting.
  </Tab>
  <Tab title="X-Plane">
    Use the custom airport package or the Global Airports folder. If the editor cannot resolve every referenced texture, add the relevant X-Plane folder when prompted.
  </Tab>
</Tabs>

<Note>
  A contribution supports one scenery package and one simulator. Submit a separate contribution for each package or simulator combination.
</Note>

## What the Division Controls

The airport's division supplies the lighting objects, their BARS IDs, and whether contributions are open. You cannot continue when the division has disabled contributions or has not supplied airport lighting data.

Your contribution aligns these objects with the simulator scenery. It does not change the division's operational lighting configuration.
