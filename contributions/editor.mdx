Use the editor to align your draft's lighting objects with the scenery. Adjust their positions, remove default lights where needed, and resolve validation errors before testing.

## Work with the Object List

Select an object name to focus it on the map and open its details. The list also shows:

- A color marker for the object.
- Its BARS ID, or **BARS ID required** when one is missing.
- A part count when one BARS object uses multiple line sections.
- A warning icon when validation found a problem.

Click the pencil icon to edit the BARS ID, or the trash icon to delete that line section.

<Note>
  Multiple line parts can share one BARS ID. They still represent one BARS object.
</Note>

## Map Tools

| Tool | Shortcut | How to use it |
| --- | --- | --- |
| Edit | `V` | Select an object, then move its editable points on the map. |
| Add object | `D` | Draw a new line with at least two points. The editor suggests a nearby unmatched BARS ID. |
| Edit source light removals | `R` | Select a start and end position on one scenery light row, then choose whether to remove or keep that section. |
| Split | `S` | Select an object, activate Split, then select a point on the line. The two resulting parts keep the same BARS ID. |
| Join | `J` | Select the first object, activate Join, then select the second. Their endpoints must be within 20 metres. |
| Measure distance | `M` | Select two map positions to create a measurement. Measurements stay on the map until cleared. |
| Snapping |  | Turn source snapping on or off. Snapping is on by default. |
| Clear measurements |  | Appears while the measurement tool has results. Removes every measurement. |

Press `Escape` to return to Edit, cancel an unfinished removal or measurement, and clear the current selection.

### Add or Correct an Object

<Steps>
  <Step title="Show useful reference layers">
    Keep the source layer you want to follow visible. **Lights**, **Markings**, and **Pavement** are common alignment references.
  </Step>
  <Step title="Edit or draw the line">
    Move the selected object's points, or use **Add object** to draw a missing line. Leave snapping on when the visible source is accurate.
  </Step>
  <Step title="Confirm the BARS ID">
    Use the BARS ID field in the Object panel. The suggestion list shows available division objects and supports arrow-key selection.
  </Step>
  <Step title="Check direction">
    Select **Reverse direction** if the line runs opposite to the intended object direction.
  </Step>
  <Step title="Read validation">
    Correct any issue attached to the object before moving on.
  </Step>
</Steps>

## Edit Source-Light Removals

Source-light removals prevent default scenery lights from appearing beneath BARS-controlled lights. You edit a section of an existing scenery light row instead of drawing an area on the map.

<Steps>
  <Step title="Activate Edit source light removals">
    Select the trash icon in the map toolbar or press `R`. The editor makes the required source-light layers visible.
  </Step>
  <Step title="Choose the action">
    Select **Remove lights** to hide the chosen section. Select **Keep lights** to erase an existing removal and preserve that section.
  </Step>
  <Step title="Select the section">
    Select the start and end on the same scenery light row. The two positions must be at least one metre apart.
  </Step>
  <Step title="Inspect the result">
    The editor updates the removal geometry. Use undo if the selected interval was wrong.
  </Step>
</Steps>

<Warning>
  Reconnect the original scenery package before changing MSFS removals. The editor cannot change a light row when it cannot find that row in the selected package.
</Warning>

## Object Panel

The **Object** tab appears on the right. Select an object to use these controls:

| Control | What it does |
| --- | --- |
| BARS ID | Assigns the line to a division object. Suggestions prioritize nearby unmatched objects. |
| Reverse direction | Reverses the coordinate order without changing the visible line. |
| Delete object | Removes the selected line section. |
| Issue message | Shows the first validation issue for the selection. |

## Scenery Panel and Reference Layers

The **Scenery** tab shows the selected package and whether it loaded correctly. You can replace the package or add missing X-Plane textures from this panel.

Open **Advanced** for display controls:

| Control | What it shows |
| --- | --- |
| Unique colors | One consistent color for every BARS ID, including multipart objects. |
| Satellite imagery | The satellite base layer, when available. |
| BARS objects | The draft geometry you are editing. |
| Division ghosts | Division objects that are still missing from the draft. |
| Lights | Source light rows and individual fixtures. |
| Markings | Painted center and hold lines. |
| Centrelines | Simulator taxi guidance. |
| Runways | Runway surfaces and centrelines. |
| Pavement | Exact surfaces and boundaries. |
| Individual fixtures | Placed lighting objects and anchors. |

Some source categories become **Required** while a tool depends on them and cannot be hidden until you leave that tool.

## Validation

The bottom of the right panel shows **Ready to test** when no issues remain. Otherwise, expand **Validation** to see the error and warning counts.

- Errors block **Test contribution**.
- Warnings identify work that needs review but do not always block testing.
- Selecting an issue focuses its object or the missing division object on the map.

Typical errors include a missing BARS ID, a conflicting duplicate object, an invalid line, or a division object that is still missing from the draft.
