Test your contribution to check that the lighting appears correctly in your scenery. Review the browser preview first, then use the BARS Pilot Client to inspect the lights in your simulator before submitting.

## Prepare the Browser Test

Your draft loads automatically when you open the test page from the editor. You can also select or drag an existing contribution XML file up to 5 MB into the upload area.

<Steps>
  <Step title="Choose the contribution draft">
    Use the draft from the editor, select another XML file, or drag one into the upload area.
  </Step>
  <Step title="Select Prepare test">
    BARS checks the draft and prepares the preview.
  </Step>
  <Step title="Inspect the preview">
    Check every object on the map before opening the contribution in the simulator.
  </Step>
</Steps>

## Preview Controls

| Control | What it shows |
| --- | --- |
| Connection lines | Lines connecting points that belong to the same BARS object. |
| Removal areas | Filled MSFS areas that hide default simulator lights. |
| Removal outlines | The same MSFS removal boundaries without a fill. |

Removal controls do not appear for X-Plane drafts.

Check for:

- Objects aligned with the intended taxiway, runway, and stand positions.
- The correct BARS ID and light type at each location.
- Complete lines with no accidental gaps or extra parts.
- MSFS removal coverage over the default lights that BARS replaces.

If the preview is wrong, return to the editor, correct the draft, and prepare the test again.

## Test in the Simulator

<Steps>
  <Step title="Start the simulator">
    Load the supported simulator and spawn at the contribution airport.
  </Step>
  <Step title="Start the BARS Pilot Client">
    Confirm it is connected to the simulator before you continue.
  </Step>
  <Step title="Select Open in BARS Pilot Client">
    Allow the browser to open the Pilot Client if it asks. The Pilot Client enters Testing Mode and loads the prepared contribution.
  </Step>
  <Step title="Inspect every light">
    Testing Mode turns every submitted light on. Check position, spacing, direction, color, and duplicate default lighting from the cockpit and an external view.
  </Step>
  <Step title="Exit Testing Mode">
    Click the close button on the Pilot Client's Testing Mode indicator when you finish.
  </Step>
</Steps>

<Warning>
  If you open Testing Mode before the simulator is running at the correct airport, exit Testing Mode first. Load the airport, then start the test again from the website.
</Warning>

Read the [Pilot Client Testing Mode guide](/pilot-client/tools#testing-mode) for the browser prompt, client indicator, simulator view, and exit controls.

## Next Steps

Select **Continue to submit** only after the browser preview and in-simulator check are correct.
